# Pixel Island

«Динамический остров» для Pixel (заточен под Pixel 10 с центральной камерой-«дыркой»), написан на Kotlin + Jetpack Compose в стиле **Material 3 Expressive**.

## Что внутри

- **Остров** — окно `TYPE_APPLICATION_OVERLAY`, «таблетка» вокруг выреза камеры. Компактный вид (иконка слева, индикатор справа), по тапу раскрывается; тап вне острова сворачивает.
- **Источники**
  - музыка/видео (`MediaSessionManager`): обложка, эквалайзер, волнистый прогресс, play/pause/next/prev;
  - звонки (`CallStyle`): отклонить / ответить / завершить, таймер разговора;
  - **Live Updates** Android 16 (`ProgressStyle`) и любые ongoing-уведомления с прогрессом: волнистая полоса, текст чипа из `shortCriticalText`;
  - навигация (`CATEGORY_NAVIGATION`): дистанция в чипе, манёвр в раскрытом виде;
  - таймеры и секундомер (ongoing-уведомление с хронометром): тикающее время;
  - обычные уведомления: короткая карточка на 6 секунд.
- **Жесты:** тап — раскрыть/свернуть, долгое нажатие — убрать текущую активность (пружинный отклик и вибрация).
- **Автозапуск** после перезагрузки и обновления приложения, если остров был включён.
- **Экран настроек** — Material 3 Expressive: `MaterialExpressiveTheme` + dynamic color (обои), `MotionScheme.expressive()` (пружины), `LargeFlexibleTopAppBar`, сегментированные списки как в настройках Pixel, `LoadingIndicator`, `MaterialShapes.Cookie9Sided`, `LinearWavyProgressIndicator`, switch с галочкой.

## Получить APK без Android Studio

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** → **Build APK** (запускается сам при push, либо кнопкой *Run workflow*).
3. Через 5–8 минут скачайте артефакт `PixelIsland-debug-apk`, внутри `app-debug.apk`. Установите на Pixel (разрешите установку из неизвестных источников).

## Сборка в Android Studio

1. Открыть папку в Android Studio (Narwhal или новее), дождаться Gradle Sync.
2. Запустить на Pixel (`minSdk 34`, `targetSdk 36`).
3. В приложении выдать три разрешения: «Поверх других окон», «Доступ к уведомлениям», «Уведомления».
4. Включить переключатель «Остров» и нажать кнопки в разделе «Проверка».

Версии в `app/build.gradle.kts` (`material3:1.5.0-beta01`, BOM, AGP 8.13) подобраны по состоянию на осень 2026 — если Studio предложит более свежие, обновите их. Expressive-компоненты живут в линейке 1.5.x, API может немного меняться между alpha/beta.

## Ограничения

- Остров — это overlay, а не часть SystemUI: на экране блокировки и поверх защищённых окон (ввод PIN, некоторые банки) его не будет.
- В ландшафте вырез уезжает на бок, остров рассчитан на портрет.
- Размеры выреза читаются из `DisplayCutout`; если система их не отдала, берутся примерные значения — подстройте «Сдвиг по вертикали» в настройках.
- Прогресс Live Updates читается из extras уведомления; у разных приложений он может отличаться.
